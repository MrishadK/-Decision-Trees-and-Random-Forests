# Decision Trees and Random Forests - Classification Task

This project explores tree-based models including Decision Tree Classifier and Random Forest Classifier.

## What is Included:
- Training a Decision Tree with depth control
- Training a Random Forest
- Comparing Decision Tree vs Random Forest Accuracy
- Feature Importance visualization
- Evaluation using:
  - Confusion Matrix
  - Precision, Recall, F1-Score
  - Cross-Validation Scores

## Tools Used:
- Python
- scikit-learn
- pandas
- matplotlib
- seaborn

## Dataset:
- Breast Cancer Dataset (or Heart Disease Dataset if available)
